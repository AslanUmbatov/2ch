# 🍀 Imageboard Viewer (2ch & 4chan)

Минималистичный и стильный клиент для просмотра имиджборд **2ch** и **4chan**. Проект создавался «для себя», поэтому основной акцент сделан на визуальную эстетику (**Liquid Glass**) и личное удобство, а не на массового пользователя.

## 🛠 Особенности и ограничения

* **Read-Only Mode:** Приложение создано исключительно для режима **«Only Read»**. Функции написания тредов или ответов на посты отсутствуют.
* **Поддержка досок:**
    * **2ch:** Основной раздел `/b/`.
    * **4chan:** Доступны абсолютно все доски.
* **Стиль:** Интерфейс выполнен в стиле **Liquid Glass** с динамическим свечением (bloom) вокруг медиа-контента.

## 🚀 Как запустить

### 🌐 Web-версия
Для запуска на компьютере:
1.  Склонируйте репозиторий.
2.  Запустите файл **`start.bat`** в корневой директории.

### 📱 Android
Для установки на смартфон:
1.  Перейдите в основную папку проекта.
2.  Найдите и установите файл **`android app.apk`**.

## ⌨️ Управление и «Скрытые» функции

Интерфейс может быть не интуитивно понятным, так как затачивался под персональные привычки:

* **Переключение ресурсов:** Нажмите на текст **«2ch»** в шапке, чтобы мгновенно переключиться на **«4chan»**, и наоборот.
* **Выбор доски:** Нажмите на название текущей доски (например, **/b/**), чтобы открыть меню выбора всех досок.
* **Скрытие треда:** Нажмите на **номер треда** в общей ленте, чтобы он исчез.
* **Удаление из архива:** В сохраненном архиве нажмите на **номер треда**, и приложение предложит его удалить.
